## Prerequisites

Before you begin, ensure you have the following installed:

- **Kotlin** 1.8 or higher
- **Java Development Kit (JDK)** 11 or higher
- **Gradle** 7.0 or higher (or any other build system configured)
- **Git** for version control

## Installation

### Clone the Repository

```bash
git clone https://github.com/diiego-s/superSpan.git
cd superSpan
```

### Build the Project

Using Gradle:

```bash
./gradlew build
```

Or using Maven (if applicable):

```bash
mvn clean install
```

## Usage

To run the project:

```bash
./gradlew run
```

For more detailed usage instructions, please refer to the [project documentation](./docs) or examine the example files in the `examples/` directory.
